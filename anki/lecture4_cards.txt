Basic	Security Technologies::L4 Airport Security Screening	Why is airport security described as 'reactive'?	Most new countermeasures were introduced <b>after</b> an attack exposed a weakness (LAX 1974 → metal detectors; Lockerbie → hold-luggage X-ray; 9/11 → liquids rules; shoe bomber → shoe scanning).	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	What countermeasure followed: (a) Lockerbie 1988, (b) 9/11, (c) the 2001 shoe bomber, (d) the 1986 Ann Marie Murphy case?	<ul><li>(a) X-ray scanning of <b>all checked luggage</b></li><li>(b) Rules on <b>liquids, gels and toiletries</b></li><li>(c) US passengers' <b>shoes scanned</b></li><li>(d) New security questions (has your bag been interfered with?)</li></ul>	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	The two types of whole-body scanner and how they differ	<ul><li><b>Millimetre-wave:</b> radio/microwaves, <b>non-ionising</b>, <b>3D</b> image</li><li><b>Backscatter:</b> low-power <b>ionising X-rays</b>, <b>2D</b> image</li></ul>	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	What can whole-body scanners detect, and what can't they?	<ul><li><b>Can:</b> metallic AND non-metallic items under clothing: liquid/plastic explosives, ceramic weapons, drugs (all missed by metal detectors); non-intrusive</li><li><b>Can't:</b> items <b>swallowed or in body cavities</b> (waves penetrate clothes, not skin)</li></ul>	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	Privacy safeguards of whole-body scanners	<ul><li>Images viewed in a <b>separate out-of-sight room</b> and <b>immediately deleted</b> (never stored)</li><li>Operator does not see the passenger</li><li>Identifying details removed (blurred faces, outlines); the US uses a <b>generic mannequin</b></li></ul>	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	Safety issues and opt-outs for body scanners	<ul><li>mm-wave emits <b>less energy than a mobile phone</b></li><li>Backscatter dose ≈ <b>2 minutes of flying</b>: insignificant but still a dose</li><li>Some countries allow <b>opt-out</b> (e.g. pregnant women) with an <b>enhanced pat-down</b></li></ul>	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	Why did the TSA remove X-ray backscatter scanners in 2013?	<b>Privacy</b> issues. X-rays are also <b>ionising</b> (can remove electrons, kill cells, cause mutations/cancer). mm-wave became the scanner of choice; some countries (e.g. Russia) still use backscatter.	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	mm-wave scanner hardware	<ul><li><b>2 antennas</b> (front and back), each <b>transmits and receives</b></li><li><b>Rotate</b> around the subject</li><li>Protected by a plastic <b>radome</b> (transparent to mm-waves)</li><li>Each antenna is an <b>array</b> of many small elements</li></ul>	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	How does a mm-wave scanner form its image?	mm-waves <b>penetrate clothing</b> and <b>reflect off skin</b> and concealed objects. Rotation gives snapshots at different angles; the array plus <b>digital beamforming</b> locates the reflection points, giving a <b>high-resolution 3D image</b>.	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	How does a mm-wave scanner detect threats?	<ul><li><b>Reflected signal strength:</b> materials reflect differently, allowing material discrimination</li><li><b>Image analysis:</b> shape detection, pattern matching</li><li><b>Automatic Target Detection (ATD)</b> algorithms: metallic/non-metallic objects, weapons, explosives (gels, plastics, powders)</li></ul>	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	Are mm-waves ionising? What is their biological effect?	<b>Non-ionising</b> (1.2×10⁻⁴ to 1.2×10⁻³ eV, far below the ~10 eV needed to break bonds). The only effect is <b>heating</b> when absorbed; significant from <b>5 mW/cm²</b>; scanners operate far below this.	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	L3 ProVision 2: key specs	20–30 GHz; <b>200–300 people/hr</b>; beam power density <b>6×10⁻⁶ mW/cm²</b> (zero heating); outputs a <b>generic mannequin</b> image, only viewed if a threat is flagged.	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	Advantages and disadvantages of walkthrough metal detectors	<ul><li><b>Pros:</b> very cheap (<b>under £5k</b>, portable ~£100); <b>~500 people/hr</b>; easy to deploy (tube stations, schools, events, nightclubs)</li><li><b>Cons:</b> <b>cannot detect non-metals</b> (3D-printed weapons, plastic explosives, drugs, animals, food); portable units less sensitive</li></ul>	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	Explain pulse induction (PI) in a metal detector: normal operation	<ol><li>A short sharp <b>current pulse</b> through the coil creates a temporary <b>magnetic field</b></li><li>The pulse ends; the field reverses polarity and <b>collapses</b></li><li>This induces a short current, the <b>reflected pulse</b> (~<b>30 µs</b>), by Faraday's law</li><li>Repeats ~<b>100 pulses per second</b></li></ol>	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	Pulse induction: what happens when metal passes through the arch?	The pulse induces a magnetic field <b>in the metal</b> of <b>opposite polarity</b>. This <b>prolongs the reflected pulse</b> (≫ 30 µs). A <b>sampling circuit</b> detects the slower-than-expected decay and raises an alarm.	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	Hard vs soft X-rays (frequency and wavelength)	<ul><li><b>Soft:</b> 10¹⁶–10¹⁸ Hz, 10 nm – 100 pm</li><li><b>Hard:</b> <b>10¹⁸–10²⁰ Hz</b>, 100 pm – 1 pm (overlap with gamma)</li></ul>	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	Describe how an X-ray tube produces X-rays (electron bombardment)	<ol><li><b>Thermionic emission:</b> a heated cathode filament 'boils off' electrons</li><li>An <b>anode</b> accelerates them through <b>10³–10⁶ V</b></li><li>They strike a metal target (<b>tungsten</b>), producing X-rays</li></ol>In an evacuated glass tube with <b>lead casing</b>.	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	What two types of radiation make up an X-ray spectrum?	<ul><li><b>Characteristic radiation:</b> discrete energy <b>peaks</b></li><li><b>Bremsstrahlung (braking) radiation:</b> a <b>continuum</b> of energies</li></ul>	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	Explain how characteristic X-rays are produced	<ol><li>An incoming electron <b>ejects an inner-shell electron</b> (photoelectron), leaving a <b>vacancy</b></li><li>A <b>higher-shell electron cascades down</b> to fill it (back to ground state)</li><li>The energy difference is emitted as an <b>X-ray</b></li><li>Shell energies are unique to each element, so the X-ray energy is <b>characteristic of the element</b></li></ol>	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	Kα vs Kβ radiation	K-peaks: the vacancy is in the <b>n = 1 (K) shell</b>. <b>Kα</b> = n=2 → n=1 transition; <b>Kβ</b> = n=3 → n=1.	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	Explain bremsstrahlung radiation and its maximum energy	Electrons pass close to the nucleus <b>without ejecting</b> a photoelectron; the path curves and they <b>decelerate (brake)</b>, emitting the lost energy as a <b>continuous</b> spectrum. <b>Maximum energy</b>: a head-on collision converts <b>all</b> the electron's energy into one X-ray.	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	Planck's law and wave–particle duality	EM radiation comes in discrete packets of energy (<b>photons</b>): <b>E = hf</b>. EM radiation behaves as waves in some cases and particles in others (wave–particle duality). Max Planck, Nobel 1918.	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	Define attenuation and its two mechanisms	The reduction in radiation intensity as it passes through a material, by <b>scattering</b> (deflection) and <b>absorption</b>.	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	What does the linear attenuation coefficient µ represent? How does it relate to the mass attenuation coefficient?	The <b>fraction of the beam absorbed or scattered per unit thickness</b> (m⁻¹); depends on X-ray energy. <b>µ = µₘ × ρ</b> (ρ = density).	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	What factors determine how well an EM wave penetrates a material? Give examples.	Wave properties (energy, frequency), material properties, and the wave–atom interactions. E.g. X-rays pass through tissue not bone; γ through lead (reduced); WiFi through brick; light stopped by cardboard; microwaves blocked by wire mesh.	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	Standard X-ray system: how it works, pros/cons	Source on one side, detectors on the other, giving a <b>2D greyscale shadowgram</b>.<br><ul><li><b>Pros:</b> high throughput, low cost; good for <b>guns/knives</b></li><li><b>Cons:</b> shape only; operator-dependent; <b>poor for explosives/drugs</b>; high false alarms</li></ul>	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	Dual-energy X-ray: how it works	<b>Two beams</b> (high-energy, less absorbed; low-energy, more attenuated); the two 2D images are compared to find the <b>effective atomic number Z_eff</b>, which is then colour-coded.	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	Define effective atomic number (Z_eff)	The <b>average atomic number</b> of a compound or mixture. It reveals light (low Z_eff, organic) vs heavy (high Z_eff, metallic) materials.	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	Transmission/backscatter X-ray systems	Two detector types:<br><ul><li><b>Transmission:</b> absorption</li><li><b>Reflection/scatter:</b> <b>density</b>; good discrimination of <b>low-Z_eff organic</b> materials</li></ul>More expensive but much better at identifying threats; <b>not as safe as mm-wave</b> for people.	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	Computed Tomography (CT) X-ray: how it works and its capabilities	<ul><li><b>Rotating</b> source with detectors moving in tandem; a 2D slice (<b>tomogram</b>) at each position</li><li>Combined by <b>tomographic reconstruction</b> into a <b>high-resolution 3D</b> image (a few mm)</li><li><b>Density + Z_eff</b> allow <b>automatic</b> alarms (cocaine, TNT; guns, knives, liquids)</li><li><b>Low throughput, high cost</b></li></ul>	SecTech L4 concept
Basic	Security Technologies::L4 Airport Security Screening	What did the Brussels Airport attack (22 March 2016) reveal, and what solutions were proposed?	3 coordinated suicide bombs in the <b>check-in area, before any security checkpoint</b>.<br><ul><li>Option 1: move checkpoints to the front doors (creates new queues/targets)</li><li>Option 2: <b>keep people moving and scan remotely</b> with nimbler or new sensors</li></ul>	SecTech L4 concept
